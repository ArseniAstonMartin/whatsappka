# Образ MinIO для linux/arm64

Сообщество MinIO распространяет сервер только исходниками. Готовый тег `minio/minio:latest` здесь не используется.

Сборка берёт фиксированные коммиты:

| Часть | Репозиторий | Метка | Коммит |
|---|---|---|---|
| Сервер | https://github.com/minio/minio | `RELEASE.2025-10-15T17-29-55Z` | `9e49d5e7a648f00e26f2246f4dc28e6b07f8c84a` |
| Клиент `mc` | https://github.com/minio/mc | `RELEASE.2025-08-13T08-35-41Z` | `7394ce0dd2a80935aded936b09fa12cbb3cb8096` |

Оба репозитория архивные. Лицензия сервера и клиента — GNU AGPL-3.0. Исходники подтягиваются во время сборки и в git проекта не копируются. Dockerfile проверяет, что `HEAD` совпал с коммитом из таблицы.

Базовые образы тоже зафиксированы digest для linux/arm64: Go 1.24.8 и Debian bookworm-slim. Бинарники собираются с `GOARCH=arm64`.

```sh
docker compose build minio
docker compose up -d minio
docker compose run --rm minio-init
```

Консоль MinIO выключена переменной `MINIO_BROWSER=off` и порт 9001 наружу не публикуется. API открыт только на `127.0.0.1`. Процесс на хосте ходит на `http://127.0.0.1:9000`, процесс внутри compose — на `http://minio:9000`. Оба профиля сервера читают `MINIO_ENDPOINT`.

Корневой пользователь нужен только хранилищу и одноразовой инициализации. Приложение получает отдельный ключ с правом читать и писать один закрытый bucket.
