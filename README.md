# Ватсапка

Веб-платформа для публикаций, сообществ и личной переписки. Пользователи ведут ленту записей, вступают в открытые и закрытые сообщества, переписываются в личных и групповых чатах, получают уведомления. Модераторы разбирают жалобы, администраторы управляют ролями, настройками и видят агрегированную статистику.

## Что умеет

- **Аккаунты.** Регистрация по логину и почте, подтверждение почты, восстановление пароля, вход через Google (при настроенном OAuth-клиенте), список сессий аккаунта с возможностью завершить любую из них.
- **Публикации.** Записи с текстом и до 10 изображениями, черновики, отложенная публикация, реакции, комментарии (глубина до 3), хештеги.
- **Лента и поиск.** Лента подписок, поиск пользователей, записей, сообществ и хештегов.
- **Сообщества.** Открытые и закрытые группы, роли, заявки на вступление, приглашения, до 100 активных участников.
- **Переписка.** Личные и групповые чаты, вложения (изображения, PDF, TXT), индикатор набора, отметки прочтения, правка сообщения в течение 24 часов, удаление с причиной для администратора группы.
- **Уведомления.** Центр уведомлений и настройки по категориям.
- **Модерация.** Очередь жалоб, временные и постоянные санкции, журнал действий.
- **Администрирование.** Пользователи и роли, настройки приложения (в том числе открытость регистрации), агрегированная статистика, журнал аудита.

Подробное руководство по экранам — в [docs/user-guide.md](docs/user-guide.md).

## Стек

| Часть | Технологии |
|---|---|
| Бэкенд | Java 21, Spring Boot 3.5, Spring Security (access JWT и refresh-сессии), Spring Data JPA, JdbcTemplate, STOMP поверх WebSocket |
| Фронтенд | Angular 21 (standalone-компоненты и сигналы), раздача через nginx с Content-Security-Policy |
| Данные | PostgreSQL 17 (миграции Flyway), Redis 8 (кэш, ограничители частоты, краткоживущее состояние), MinIO (объекты, совместимые с S3) |
| Фоновые задачи | Отдельный процесс worker: очередь заданий, transactional outbox, обработка медиа, очистка устаревших данных |
| Развёртывание | Docker Compose; внешний стенд — Coolify на Linux ARM64 |

## Быстрый старт (локально)

Нужны Docker с Compose v2 и свободные порты 4200 и 8080 на `127.0.0.1`.

1. Скопируйте шаблон и задайте значения:

   ```sh
   cp .env.example .env
   ```

   Замените все `local-…-change-me` на свои значения. `JWT_SECRET` — не короче 32 байт.

2. Запустите стек:

   ```sh
   docker compose up -d --build
   ```

   Миграции базы выполняются автоматически сервисом `migrate`. Backend стартует после них.

3. Откройте `http://localhost:4200`.

Первого администратора можно создать через `BOOTSTRAP_ADMIN_*` в `.env` (подробности — в [docs/operations.md](docs/operations.md)). После первого запуска эти переменные нужно очистить.

### Демонстрационные данные

Для локальной проверки интерфейса есть набор данных. Он подключается только явно: профиль `demo`, `DEMO_ENABLED=true` и `DEMO_PASSWORD` не короче 10 символов. В production и в процессе worker он не работает.

```sh
SPRING_PROFILES_ACTIVE=backend,demo DEMO_ENABLED=true DEMO_PASSWORD=<пароль-не-короче-10> docker compose up -d
```

## Структура репозитория

```
backend/     Java-приложение: API (profile backend) и worker (profile worker)
frontend/    Angular SPA и конфигурация nginx
infra/       образ MinIO, скрипты резервного копирования и восстановления
docs/        документация продукта
compose.yaml локальный и серверный стек
```

## Сборка

Бэкенд: `cd backend && ./mvnw package`. Фронтенд: `cd frontend && npm ci && npm run build`. Автоматические тесты в репозиторий пока не включены.

## Ограничения текущей версии

- Тёмная тема не предусмотрена.
- Резервное копирование и восстановление описаны в [docs/operations.md](docs/operations.md). Внешняя копия пока не настроена.
- Доступ к PostgreSQL, Redis и MinIO с хоста не предусмотрен: эти сервисы работают во внутренней сети Docker.
